Add a document

SEC filings, FDIC data, complaints, and stress tests arrive on their own when you run an update. Upload only what the pipeline can't fetch itself: earnings transcripts (paywalled) and FFIEC ZIPs (download-blocked).

  1. Choose the fileTranscripts: txt, html, or pdf. Regulatory data: the ZIP exactly as downloaded from the FFIEC site.
  2. Tell it what it isTranscripts need the company and quarter — that's how the corpus files and cites them.
  3. Add, then run the update belowThe file waits in the inbox until a run hashes it, writes its provenance record, and indexes it.

Run the update

Fetches new public filings and data, ingests inbox files, re-extracts, validates, rebuilds. If anything fails its checks, the current database keeps serving — a bad run can't break the app.
