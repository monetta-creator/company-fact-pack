How it works.

Two pipelines share one database: build fills it, ask proves things out of it.

The logic, in six commitments

  1. Structure before searchDocuments are cut on their real seams — filing items, exhibits, tables kept whole — and each piece is labeled with its document, period, and company before it's indexed.
  2. Filter before relevanceThe question's company and time window narrow the field first; only then do keyword and semantic search compete, get fused, and get reranked.
  3. Numbers have one homeFigures come from the metric store, where each has a single definition and a source pointer — never from prose, where the basis is unknowable.
  4. Citation is a gate, not decorationThe answer may cite only its own frozen evidence pack. Anything else is removed and logged. Wrong citations are never repaired into plausible ones.
  5. Verify, then show the flagsEvery quote and figure is string-matched against its source; a second model judges each claim. Failures render as flags — the answer is never quietly edited.
  6. Bounded agencyDeep mode is a loop with hard caps — rounds, calls, characters, wall clock — enforced by code, not by asking the model nicely.
