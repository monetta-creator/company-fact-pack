How to use it.

Three things: ask, read the receipts, keep it fresh.

Ask

  1. Type a questionNumbers, narratives, events, or structure — the router picks the right path. Name a year or quarter to narrow it.
  2. Check Deep for hard questionsRuns a bounded research loop: several rounds of searching and metric queries before answering. Slower, more thorough.
  3. Ask follow-upsCitations carry across the conversation — [C3] means the same source it did two questions ago.

Read the receipts

  1. Tap any citation chip[C…] is a document excerpt, [obs:…] a governed number, [ev:…] an event, [brief:…] reviewed doctrine. The panel shows the exact source text.
  2. Trust the Verified lineEvery quote and figure was matched against its cited source, then a second model judged each claim. Problems appear as red flags — never silently fixed.
  3. Removed citations are honesty, not errorsIf the answer cited something outside its own evidence, that citation was stripped and listed. The claim stands as unproven text.

Keep it fresh

  1. Run an update when Freshness says soOne button on the Update page. New filings, trust reports, and complaint data arrive on their own schedules.
  2. Upload what the pipeline can't fetchEarnings transcripts (paywalled) and FFIEC ZIPs (bot-blocked). Pick the type, fill the two fields, done.
  3. Review drafts before they countAnything a model wrote — briefs, entities, products — waits on the draft/model-content git branch. Merge what passes your read; only then does it join the evidence.

From the terminal

uv run factpack ask "…"        # answer with citations
uv run factpack ask --deep "…" # bounded research loop
uv run factpack search "…"     # raw retrieval, no generation
uv run factpack metrics "…"    # query the number store
uv run factpack cost           # what the model calls have cost
make fetch extract validate compile   # the update, by hand
